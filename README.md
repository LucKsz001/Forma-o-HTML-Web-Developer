## Sobre

Repositório dedicado aos meus estudos e práticas da **Formação HTML Web Developer** da DIO. 

O objetivo desta formação é proporcionar a base para criar as primeiras páginas web, ensinando na prática como estruturar a marcação de uma página, como funciona cada tag, os elementos semânticos e as boas práticas de desenvolvimento front-end.

**Pré-requisitos atendidos:** Conhecimentos básicos em Lógica de Programação e Pensamento Computacional.

---

## Objetivo do Repositório

- Documentar minha evolução e anotações durante a formação.
- Armazenar os desafios de código e desafios de projeto propostos nas aulas.
- Construir um portfólio prático com aplicações reais em HTML.

---

## Metodologia e Atividades (DIO)

Durante a formação, o aprendizado é consolidado através de:

- **Desafio de Código:** Resolução de problemas práticos para testar os conhecimentos adquiridos em aula.
- **Desafio de Projeto:** Construção de projetos práticos para compor o portfólio.
- **Meta de Estudo:** Planejamento de rotina para conclusão da formação.
- **Ranking:** Avaliação de performance baseada em Submissões de Qualidade (SQ) e Interações de Qualidade (IQ) no fórum.
