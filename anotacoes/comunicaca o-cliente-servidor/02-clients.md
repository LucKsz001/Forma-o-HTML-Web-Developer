# 02 — O que são Clients

## 🧑‍💻 Conceito de Client no contexto web

**Cliente** é o **lado que recebe a informação** de algum lugar. É representado por notebooks, celulares, tablets e outros dispositivos que **se comunicam através da internet** com outro computador.

Por isso a internet é chamada de **rede mundial de computadores**:

- 🟢 **Cliente** → lado que **recebe** a informação
- 🔵 **Servidor** (*server*) → o próprio nome já diz: ele **serve** informações para os clientes

## 🌍 Como funciona na prática

Quando você tem um **site**:

1. Você **hospeda** o site em um **servidor**.
2. Quando alguém procura o seu site, a busca acontece na internet.
3. A pessoa encontra um **computador** (o servidor) que tem os **arquivos do site**.
4. Esse computador **envia a informação de volta** para o cliente.

## 📦 Arquivos estáticos

Quando você pesquisa algo na internet, o **servidor retorna arquivos**:

- **HTML**
- **CSS**
- **JavaScript**
- **Imagens**
- Outros tipos de arquivos

Esses são chamados de **arquivos estáticos**.

> ⚠️ **Atenção:** a **velocidade da conexão** afeta o usuário, além do tamanho dos arquivos (arquivos grandes demoram mais).

## ✅ Boas práticas e testes

- **Compatibilidade entre navegadores (Browsers):** os navegadores seguem um padrão, mas a informação pode se comportar diferente dependendo do navegador — isso é a **compatibilidade**.
- **Responsividade:** a interface precisa funcionar em diferentes telas:
  - 🖥️ Desktop
  - 💻 Notebook (tela menor)
  - 📱 Celular (horizontal e vertical)
  - 📺 TVs

## 🧭 Navegadores (área do cliente)

Os **navegadores** são **programas instalados nos dispositivos** para abrir/executar arquivos HTML, CSS, JavaScript, imagens e outros. Eles são responsáveis por **interpretar** esses arquivos.

Existem vários navegadores (Chrome, Firefox, Edge, Safari, etc.), mas todos seguem o padrão do **W3C** (*World Wide Web Consortium*).

## 🌐 Aplicações Web

### Navegador é uma aplicação web?

- Através do **cliente**, é preciso acessar os **navegadores** para chegar a um **servidor**.
- O **servidor** pode se conectar com um **banco de dados**.
- O **lado do cliente não tem essa capacidade**.
- O **banco de dados do lado do servidor faz parte da aplicação como um todo**.

> **Exemplo:** em um e-commerce, os **clientes estão cadastrados nesse banco de dados**.

### Definição de Aplicação Web

**Aplicação Web** são soluções criadas que possuem a **internet como meio de comunicação** entre cliente e servidor, **não sendo necessária a sua instalação**.

> ✅ **É aplicação web:** acessar o **YouTube pelo navegador**.
> ❌ **NÃO é aplicação web:** acessar o YouTube pelo **aplicativo instalado**.
