# 04 — Linguagens de Programação Web

## 📖 O que é Linguagem de Programação

**Linguagem de programação** é uma **linguagem escrita e formal** que especifica um conjunto de **instruções e regras** usadas para gerar **programas (software)**.

## 🌐 Linguagens Server-Side

São as linguagens que **rodam no lado do servidor**.

- Processam a lógica do servidor, acessam banco de dados, autenticam usuários, etc.
- Exemplos:
  - **PHP**
  - **JavaScript** (Node.js)
  - **Java**
  - **Ruby**
  - **Python**
  - **C#**

## 💻 Linguagens Client-Side

São as linguagens que **rodam no lado do cliente** (navegador), em aplicações web.

- Exemplo principal: **JavaScript**
- Também inclui **HTML** e **CSS** (embora não sejam linguagens de programação propriamente ditas — HTML é de marcação e CSS é de estilo).

## 🔍 Diferença resumida

| Aspecto | Server-Side | Client-Side |
|---------|-------------|-------------|
| Onde roda | No servidor | No navegador |
| O usuário vê o código? | ❌ Não | ✅ Sim |
| Exemplos | PHP, Java, Ruby, Python, Node.js | JavaScript, HTML, CSS |
| Função | Regras de negócio, banco, autenticação | Interface, interatividade |

> ⚠️ **Atenção:** **JavaScript** aparece nas duas listas porque pode rodar tanto no **navegador (client-side)** quanto no **servidor (server-side, via Node.js)**.
