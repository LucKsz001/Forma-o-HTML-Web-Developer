# 04 — Linguagens de Programação Web

## 📖 O que é Linguagem de Programação
Linguagem **escrita e formal** com **instruções e regras** para gerar **programas (software)**.

## 🌐 Server-Side
Rodam no **lado do servidor**.
- Processam lógica, acessam banco, autenticam.
- Exemplos: **PHP, Node.js (JS), Java, Ruby, Python, C#**.

## 💻 Client-Side
Rodam no **lado do cliente** (navegador).
- Exemplo: **JavaScript**.
- Inclui também **HTML** e **CSS** (não são linguagens de programação, mas rodam no cliente).

## 🔍 Diferença resumida
| Aspecto | Server-Side | Client-Side |
|---------|-------------|-------------|
| Onde roda | No servidor | No navegador |
| Código visível? | ❌ Não | ✅ Sim |
| Exemplos | PHP, Java, Python | JavaScript, HTML, CSS |

> ⚠️ **JavaScript** roda nos dois lados (navegador e servidor via Node.js).
