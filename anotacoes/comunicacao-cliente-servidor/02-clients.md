# 02 — O que são Clients

## 🧑‍💻 Conceito de Client
**Cliente** é o **lado que recebe a informação**. É representado por notebooks, celulares, tablets, etc., que **se comunicam através da internet**.
A internet é a **rede mundial de computadores**:
- 🟢 **Cliente** → lado que **recebe** a informação.
- 🔵 **Servidor** → **serve** informações para os clientes.

## 🌍 Como funciona na prática
1. Você **hospeda** o site em um **servidor**.
2. O cliente busca o site na internet.
3. Encontra o **computador** com os **arquivos do site**.
4. O servidor **envia a informação de volta**.

## 📦 Arquivos estáticos
O **servidor retorna arquivos**: HTML, CSS, JavaScript, Imagens, etc. São chamados de **arquivos estáticos**.
> ⚠️ A **velocidade da conexão** e o **tamanho dos arquivos** afetam o usuário.

## ✅ Boas práticas e testes
- **Compatibilidade entre navegadores:** comportamentos diferentes entre browsers.
- **Responsividade:** adaptar para Desktop, Notebook, Celular e TVs.

## 🧭 Navegadores (área do cliente)
São **programas instalados nos dispositivos** para interpretar os arquivos. Seguem o padrão do **W3C**.

## 🌐 Aplicações Web
- O **servidor** se conecta a um **banco de dados**, o **cliente não**.
- **Aplicação Web:** soluções que usam a internet como meio de comunicação, sem precisar de instalação.
> ✅ **É aplicação web:** YouTube pelo navegador.
> ❌ **NÃO é aplicação web:** YouTube pelo aplicativo instalado.
