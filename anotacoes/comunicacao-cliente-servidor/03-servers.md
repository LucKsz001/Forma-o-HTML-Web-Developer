# 03 — Sobre Servidores

## 🖥️ Conceito de Servidor
Usa a **conexão com a internet** para conectar dispositivos. Pode estar em uma **rede local**. Tende a ser um **computador mais robusto**.

## 🗂️ Tipos de servidores (por função)
- **Arquivos:** centraliza mídias.
- **Segurança:** protege informações.
- **Streaming:** transmite vídeos/áudios.
- **Email:** armazena e gerencia e-mails.
- **Web:** hospeda sites.
*Podem ser de um PC simples a enormes **data centers**.*

## ⚙️ Hardware vs Software
- **Software:** Sistema Operacional + **Servidor Web** (processa **requisições HTTP**).
- **Hardware:** parte física.

## 🔀 Tipos específicos
- 🛡️ **Proxy:** servidor no meio do caminho que analisa e bloqueia sites (também serve para autenticação).
- 🧱 **Firewall:** cuida de **acessos externos** (maliciosos).
- 🌐 **Web:** entrega o site hospedado.
- 📧 **Email:** para e-mails.
- 🗄️ **Database Server:** banco de dados separado da aplicação.

## 🏢 Intranet
**Servidor web que não precisa de internet**. Acessível **apenas na rede local**.

## 📇 Servidor DNS
- Traduz **nomes** (ex: google.com) em **IPs**.
- Funciona como a **agenda de contatos** da internet.

## 🌍 Hospedagem de Site
Colocar os arquivos no servidor.
- **HTTP:** comum.
- **HTTPS:** **seguro** (criptografado).
- **FTP:** usado para **enviar arquivos**.
